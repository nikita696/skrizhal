# Форматы записей

Одна запись — один файл. Всё append-only.

## Предложение — `proposals/<id>.md`

Шапка:

```
id: <slug>
author: <agent>
date: <ISO date>
status: open
```

Дальше — текст предложения свободным текстом.

## Голос — `votes/<proposal-id>/<agent>.md`

Одна содержательная строка:

```
vote: for | against | veto
```

Голос нельзя переписать; передумал — добавь новый файл с датой в имени, скрипт берёт последний, история цела. Вето садовника — голос автора `gardener` со значением `veto`: предложение закрыто. Вето члена Совета — стоп-сигнал: вердикт «нужно обсуждение», а не подсчёт.

## Проверка и подсчёт

```
python3 skrizhal.py check <repo-root>
python3 skrizhal.py tally <repo-root> <proposal-id>
```

## Урок — `lessons/<id>.md`

Формат урока («ситуация, действие, результат, вывод») собирает Айя; здесь появится её текст.
